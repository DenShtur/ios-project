# Спецификации для приложения чата на iOS (SwiftUI)

## Основные функции
- Регистрация и аутентификация пользователей.
- Отправка и получение сообщений в реальном времени.
- Поддержка групповых чатов и личных сообщений.
- Возможность отправки медиафайлов (изображения, видео).

## Интерфейс
- Современный и интуитивно понятный интерфейс.
- Поддержка жестов для навигации.

## Кеширование
- Локальное хранение сообщений и данных пользователей.

## Тестирование
- Полное покрытие юнит-тестами для всех компонентов.

## Доступность
- Поддержка VoiceOver и других функций доступности.

2. Стикеры и медиа: реализовать в первом релизе или позже?
3. Аутентификация: токен пользователя Mattermost или OAuth?
4. Синхронизация истории сообщений при запуске приложения?
